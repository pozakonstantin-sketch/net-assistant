# Прямые команды ассистента

Ассистент понимает **обычные фразы по-русски** — специальный синтаксис не нужен.
Ниже — что можно написать в Telegram (или в панели) и что произойдёт.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | справка и примеры |
| `/status` | какие устройства на связи, какая модель ИИ |
| `/models` | список моделей ИИ кнопками — нажать и переключить |
| `/model ИМЯ` | переключить модель сразу: `/model opencode/mimo-v2.6-flash-free` |
| `/pending` | что ждёт подтверждения |
| `/panel` | открыть панель (устройства, чат, журнал) |
| `/reset` | очистить контекст диалога |

## ПК (`pc-desktop`)

| Что написать | Что произойдёт |
|---|---|
| «Какой процессор и сколько памяти?» | сведения об ОС, CPU, памяти, аптайме |
| «Сделай скриншот» | снимок экрана, приходит картинкой |
| «Заблокируй экран» | блокировка как Win+L |
| «Какие процессы едят память?» | список процессов по памяти или CPU |
| «Поставь громкость 30%» / «Выключи звук» | громкость 0–100 или mute |
| «Покажи папку C:\Users» | содержимое каталога |
| «Прочитай файл C:\...\notes.txt» | текст файла (ограниченный размер) |
| «Создай папку C:\temp\проба» | создать каталог |
| «Создай файл ... с текстом ...» | записать/перезаписать файл ⚠️ |
| «Удали файл ...» | удалить файл или каталог ⚠️ |
| «Заверши процесс chrome» | завершить процесс по имени или PID ⚠️ |
| «Выключи компьютер через 5 минут» | shutdown / restart / sleep / hibernate / logoff ⚠️ |
| «Отмени выключение» | отмена запланированного питания |
| «Проверь сеть» | адреса, шлюз, пинг |
| «Выполни в PowerShell: ...» | произвольная команда ⚠️ (в полном доступе — сразу, иначе с подтверждением) |

## Роутер (`router`)

| Что написать | Что произойдёт |
|---|---|
| «Кто подключён к Wi-Fi?» | DHCP-аренды и WiFi-клиенты |
| «Выключи Wi-Fi» / «Включи Wi-Fi» | радиомодуль ⚠️ |
| «Перезагрузи роутер» | перезагрузка, связь пропадёт на 1–2 минуты ⚠️ |
| «Отключи от Wi-Fi MAC aa:bb:cc:dd:ee:ff» | отключить или заблокировать клиента ⚠️ |
| «Проверь сеть на роутере» | адреса и маршруты |
| «Выполни на роутере: ...» | произвольная команда sh ⚠️ |
| «Создай/удали файл на роутере» | файловые операции ⚠️ |

## Телефон (`virus`)

| Что написать | Что произойдёт |
|---|---|
| «Сколько заряда?» | батарея и состояние питания |
| «Включи фонарик» / «Выключи фонарик» | вспышка |
| «Покажи уведомление: готово» | уведомление на экране |
| «Скажи вслух: привет» | синтез речи |
| «Какая WiFi-сеть?» | SSID, IP, скорость |
| «Где телефон?» | местоположение |
| «Открой Telegram» | запуск приложения по пакету |
| «Какие приложения установлены?» | список приложений |
| «Какое приложение открыто?» | активное приложение |
| «Останови приложение ...» | принудительная остановка ⚠️ |
| «Покажи SMS» | последние сообщения |
| «Отправь SMS на +7... текст ...» | отправка ⚠️ |
| «Сделай снимок экрана телефона» | PNG-ссылка |
| «Что на экране?» | дерево интерфейса: тексты и координаты |
| «Нажми в точку 500 1200» | касание |
| «Свайп от 500 1500 к 500 400» | свайп |
| «Введи текст hello123» | ввод в активное поле (латиница и цифры) |
| «Нажми Домой / Назад» | системная кнопка |

## Модели ИИ

Список берётся из CLI `opencode` (бесплатные модели). Текущая хранится в
`data/llm_model.txt`, выбор действует сразу и на бота, и на панель.

```
/models                       ← кнопки в Telegram
/model opencode/deepseek-v4.1-flash-free
/model opencode/mimo-v2.6-flash-free
```

## Подтверждения

⚠️ — действия, которые бот сначала показывает кнопкой «Подтвердить».
Это защита от случайного выключения ПК, удаления файлов, отключения Wi-Fi,
перезагрузки роутера и отправки SMS. Отключить проверку целиком можно
`REQUIRE_CONFIRM=false`, но лучше этого не делать.
